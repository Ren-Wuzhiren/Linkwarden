# Linkwarden 本地运行手册

## 目标

在 Windows 主机上运行 Linkwarden 源码，而不是运行官方容器镜像。PostgreSQL 和 Meilisearch 由 Docker 提供，web/worker 直接运行在工作区，便于修改代码和打断点。

## 前置条件

- Docker Desktop 已安装并启动。
- 项目内 Node 20 运行时位于 `reference/tools/node-v20.20.2-win-x64`。
- Yarn 4.12.0 位于 `reference/tools/corepack/v1/yarn/4.12.0/yarn.js`。
- 上游 `.env` 已存在，且没有被 Git 跟踪。

## 启动依赖

在 `reference/linkwarden` 中执行：

```powershell
$docker = "$env:LOCALAPPDATA\Programs\DockerDesktop\resources\bin\docker.exe"
& $docker compose `
  --project-directory . `
  -f docker-compose.yml `
  -f ../../deploy/reference/docker-compose.override.yml `
  up -d postgres meilisearch
```

固定端口：

- PostgreSQL：`localhost:55432`
- Meilisearch：`localhost:7700`

## 安装依赖

不要直接使用系统 Node 24，也不要把包下载到 C 盘全局 Yarn 缓存：

```powershell
$node = "..\tools\node-v20.20.2-win-x64\node.exe"
$yarn = "..\tools\corepack\v1\yarn\4.12.0\yarn.js"
$env:YARN_CACHE_FOLDER = "..\tools\yarn-cache"
$env:YARN_ENABLE_GLOBAL_CACHE = "false"

& $node $yarn install --mode=skip-build
& $node $yarn prisma:generate
& $node $yarn patch-package
& $node $yarn workspace "@linkwarden/web" run postinstall
```

## 应用数据库迁移

```powershell
& $node $yarn prisma:deploy
```

## 启动 web 与 worker

Next.js telemetry 会尝试写 `AppData\Roaming\nextjs-nodejs`，在当前 Windows 环境可能触发跨卷重命名错误，因此必须禁用它：

```powershell
$env:NEXT_TELEMETRY_DISABLED = "1"
& $node $yarn concurrently:dev
```

浏览器访问 `http://localhost:3000`。web 和 worker 共用当前终端，按 `Ctrl+C` 停止。

## IDEA 导入

1. 自有仓库用 `File -> Open` 打开 `D:\WebCollectingAndContentSavingSystem`。
2. 参考仓库另开一个窗口，打开 `D:\WebCollectingAndContentSavingSystem\reference\linkwarden`。
3. 在自有仓库的 Project Structure 中将 `reference` 标记为 Excluded。
4. Java SDK 选择 JDK 17；前端 Node 解释器选择项目内 Node 20。
5. 上游源码的 Yarn 和 Prisma 命令按本手册在终端运行。

## 停止

在 web/worker 终端按 `Ctrl+C`，然后停止依赖：

```powershell
& $docker compose `
  --project-directory . `
  -f docker-compose.yml `
  -f ../../deploy/reference/docker-compose.override.yml `
  down
```

不要添加 `-v`，否则会删除本地数据库和搜索数据卷。
