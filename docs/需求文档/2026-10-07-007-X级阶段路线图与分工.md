## 编号规则

从阶段 1.4 起使用三段式编号：

```text
X.Y.Z
```

- `X`：大阶段。
- `Y`：阶段内的业务阶段或子问题。
- `Z`：该阶段中的一个可验收增量。

不再使用 `1.4B3.1` 这类十进制、字母和点号混排的编号。历史文档和 Git 历史不强制重命名，旧编号映射保留在需求文档索引中。

## 统一分工

- 用户负责：后端业务代码、数据库迁移、手工验证、学习笔记和最终验收解释。
- Codex 负责：架构讲解、任务拆解、代码审查、测试建议、工程化文档；从阶段 7 开始负责 Vue 前端实现并逐组件讲解。
- 双方共同负责：确认接口契约、数据模型、失败路径和验收标准，完成阶段验收并形成独立 commit。
