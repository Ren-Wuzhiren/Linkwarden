## 目标

让仓库根目录成为一个可被 Maven 和 IDEA 识别的聚合工程，同时将 Spring Boot 依赖放在 `backend` 模块中。

## 最终结构

```text
pom.xml                 # Maven 聚合工程，packaging = pom
backend/
  pom.xml               # Spring Boot 模块
  src/main/java/...     # 后端源码
  src/main/resources/   # 模块配置
deploy/local/           # MySQL/Redis 本地开发依赖
```
