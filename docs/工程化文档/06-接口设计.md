# 接口设计

## 通用约定

- 基础路径：`/api/v1`
- 鉴权：`Authorization: Bearer <token>`
- Content-Type：`application/json`
- 时间：ISO 8601 UTC 字符串
- 分页：游标分页，返回 `nextCursor`
- 请求 ID：响应头 `X-Request-Id`，错误体中同时返回

成功响应：

```json
{
  "data": {},
  "message": "OK",
  "requestId": "..."
}
```

失败响应：

```json
{
  "code": "LINK_ALREADY_EXISTS",
  "message": "链接已存在",
  "details": {},
  "requestId": "..."
}
```

## 鉴权

### POST /auth/register

仅在 `app.registration-enabled=true` 时可用。

```json
{
  "username": "student",
  "email": "student@example.com",
  "password": "..."
}
```

### POST /auth/login

```json
{
  "username": "student",
  "password": "..."
}
```

返回 `token`、`expiresAt` 和当前用户摘要。

### POST /auth/logout

注销当前 Token；重复注销返回成功。

### GET /auth/me

返回用户 ID、用户名和偏好设置。

## 集合

- `GET /collections`：返回当前用户的全部集合和链接数量。
- `POST /collections`：创建集合，名称在用户范围内唯一。
- `PATCH /collections/{id}`：修改名称和描述。
- `DELETE /collections/{id}`：拒绝删除 Inbox；其他集合存在链接时返回 `409`。

## 链接与任务

### POST /links

```json
{
  "url": "https://example.com/article",
  "collectionId": 1,
  "tagIds": [1, 2],
  "title": "",
  "description": ""
}
```

行为：

1. 规范化 URL 并计算哈希。
2. 相同用户下已存在时返回已有链接和 `409 LINK_ALREADY_EXISTS`。
3. 创建链接和 `PENDING` 任务。
4. 返回 `link` 和 `job`，不等待抓取完成。

### GET /links

查询参数：

- `collectionId`
- `tagId`
- `cursor`
- `limit`，默认 20，最大 100

### GET /links/{id}

返回链接、当前最新成功任务和资产元数据。

### PATCH /links/{id}

允许修改标题、描述、集合和标签，不允许直接修改 `normalizedUrl`。

### DELETE /links/{id}

删除链接及其任务和资产记录，返回 `202`；物理文件异步清理。

### POST /links/{id}/recapture

为已有链接创建新的 `PENDING` 任务。已有任务处于 `PENDING/RUNNING` 时返回 `409 CAPTURE_IN_PROGRESS`。

## 标签

- `GET /tags`：返回标签和链接数量。
- `POST /tags`：创建标签。
- `PATCH /tags/{id}`：修改名称。
- `DELETE /tags/{id}`：删除标签及链接关联，不删除链接。
- `PUT /links/{id}/tags`：替换链接标签集合。

## 任务

### GET /jobs/{id}

```json
{
  "id": 1001,
  "linkId": 42,
  "status": "RUNNING",
  "attemptCount": 1,
  "maxAttempts": 3,
  "errorCode": null,
  "errorMessage": null,
  "assets": []
}
```

前端在 `PENDING/RUNNING` 时每 3 秒轮询，终态后停止。

## 资产

- `GET /assets/{id}/metadata`：返回 MIME、大小、SHA-256 和创建时间。
- `GET /assets/{id}`：鉴权后返回文件流。
- HTML 资产使用 `Content-Disposition: attachment`，不在同源内直接内联执行。

## 搜索

### GET /search

查询参数：

- `q`：标题、描述、正文、标签的普通搜索词。
- `tag`：标签精确过滤，可重复。
- `collectionId`：集合过滤。
- `before`、`after`：创建时间范围。
- `cursor`、`limit`。

返回链接与当前资产元数据，不返回完整 HTML 或正文。

## 健康检查

- `GET /health/live`：进程存活。
- `GET /health/ready`：数据库和 Redis 可达。

## 错误码

- `AUTH_REQUIRED`：401
- `FORBIDDEN_RESOURCE`：403
- `RESOURCE_NOT_FOUND`：404
- `VALIDATION_FAILED`：400
- `LINK_ALREADY_EXISTS`：409
- `CAPTURE_IN_PROGRESS`：409
- `UNSAFE_URL`：422
- `CAPTURE_FAILED`：任务失败状态，不直接用作 HTTP 500
- `INTERNAL_ERROR`：500
