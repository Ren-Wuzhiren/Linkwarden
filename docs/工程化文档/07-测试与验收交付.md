# 测试与验收交付

## 当前实际状态（2026-10-08）

阶段 0 到 X1 用户与鉴权已完成的基础设施、注册、登录和会话测试：

- `mvn -pl backend test`：86 项通过，0 失败，0 错误，0 跳过。
- 请求 ID：合法、缺失、非法字符、长度超限、响应头和 `ThreadLocal`/MDC 清理。
- 统一响应与错误：成功响应快照、错误码、`ErrorResponse`、业务异常和 MockMvc 异常映射。
- 健康检查：live/ready 成功和失败分支；MySQL、Redis 不可用时的 503 契约。
- MyBatis-Plus：分页拦截器注册和 Mapper 扫描。
- Flyway 与用户映射：Testcontainers 启动真实 MySQL 8.4 和 Redis 7.4，执行 V1，验证主键回写、字段映射和用户名唯一约束。
- 鉴权基础设施：BCrypt Bean、配置绑定、`SaTokenDaoForRedisTemplate` 的写入、读取、TTL 和删除。
- 注册输入：用户名/邮箱 `strip()`、全角空白、邮箱小写和空白转 `null`；DTO 校验发生在规范化之后。
- 注册业务：`AuthService` 覆盖注册关闭、重复用户名、重复邮箱、BCrypt 哈希、固定时间和唯一键冲突翻译。
- 注册 HTTP：`AuthControllerTest` 覆盖 `201 Created`、字段校验、注册关闭、用户名/邮箱冲突和非法 JSON。
- 注册集成：`AuthRegistrationIntegrationTest` 使用真实 MySQL、Redis、BCrypt、`AuthService` 和 MockMvc，验证用户真实落库、密码哈希和重复冲突。
- 登录与会话：`AuthServiceTest` 和 `AuthControllerTest` 覆盖登录失败、登录成功、当前用户、退出和重复退出。
- 会话集成：`AuthSessionIntegrationTest` 使用真实 MySQL、Redis、BCrypt 和 Sa-Token，验证注册、登录、`/me`、退出以及原 Token 失效。
- 知识边界：集合、链接、标签、任务、资产和搜索尚未实现，不能把鉴权闭环等同于完整 MVP 闭环。

## 后续阶段测试计划

### 单元测试

- URL 规范化：大小写、默认端口、fragment、尾斜杠和查询参数。
- URL 哈希与重复检测。
- SSRF：localhost、私网 IPv4、IPv6、保留网段和 DNS 多地址。
- 任务状态机：合法迁移、非法迁移、重试上限和锁定恢复。
- 资产路径生成与 SHA-256 计算。
- 搜索参数解析和 SQL 条件构建。

### 集成测试

- Testcontainers 启动 MySQL 和 Redis，执行 Flyway 迁移。
- MockMvc 验证登录、集合、链接、标签、任务和权限隔离。
- 使用本地 HTTP 页面夹具验证 Playwright 生成 HTML、PDF 和截图。
- 模拟 301/302、超时、500、超大响应和私网重定向。
- 并发启动 2 个 Worker，验证同一 Job 只被消费一次。

### 前端测试

- 保存表单校验：URL 格式、重复提交和错误反馈。
- 任务轮询：进行中、成功、失败和停止轮询。
- 链接详情：正文、截图、PDF 和 HTML 标签切换。
- 搜索：普通词、标签和集合过滤。

### 手工验收

使用至少 30 个真实 URL，覆盖：

- 普通新闻或博客页面。
- 中文技术文章。
- GitHub 项目页。
- 带大量图片的页面。
- 重定向和短链接。
- 超时、403、404 和拒绝访问页面。
- 直接 PDF 和直接图片 URL。
- 重复保存和重新采集。

## 验收指标

- 首次保存成功率 >= 90%。
- 中位完成时间 <= 30 秒。
- 任务失败后错误原因可见。
- Worker 重启后待处理任务不丢失。
- 同一 URL 不会在同一用户下生成多个链接。
- 不允许保存 localhost、私网和云元数据地址。
- 中文和英文标题、正文均能检索。
