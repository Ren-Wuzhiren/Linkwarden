# 测试与验收交付

## 单元测试

- URL 规范化：大小写、默认端口、fragment、尾斜杠和查询参数。
- URL 哈希与重复检测。
- SSRF：localhost、私网 IPv4、IPv6、保留网段和 DNS 多地址。
- 任务状态机：合法迁移、非法迁移、重试上限和锁定恢复。
- 资产路径生成与 SHA-256 计算。
- 搜索参数解析和 SQL 条件构建。

## 集成测试

- Testcontainers 启动 MySQL 和 Redis，执行 Flyway/Liquibase 迁移。
- MockMvc 验证登录、集合、链接、标签、任务和权限隔离。
- 使用本地 HTTP 页面夹具验证 Playwright 生成 HTML、PDF 和截图。
- 模拟 301/302、超时、500、超大响应和私网重定向。
- 并发启动 2 个 Worker，验证同一 Job 只被消费一次。

## 前端测试

- 保存表单校验：URL 格式、重复提交和错误反馈。
- 任务轮询：进行中、成功、失败和停止轮询。
- 链接详情：正文、截图、PDF 和 HTML 标签切换。
- 搜索：普通词、标签和集合过滤。

## 手工验收

使用至少 30 个真实 URL，覆盖：

- 普通新闻或博客页面。
- 中文技术文章。
- GitHub 项目页。
- 带大量图片的页面。
- 重定向和短链接。
- 超时、403、404 和拒绝访问页面。
- 直接 PDF 和直接图片 URL。
- 重复保存和重新采集。

## 验收指标

- 首次保存成功率 >= 90%。
- 中位完成时间 <= 30 秒。
- 任务失败后错误原因可见。
- Worker 重启后待处理任务不丢失。
- 同一 URL 不会在同一用户下生成多个链接。
- 不允许保存 localhost、私网和云元数据地址。
- 中文和英文标题、正文均能检索。

## 交付清单

- 可运行源码和锁定的依赖版本。
- README：环境、启动、配置和演示步骤。
- 数据库迁移脚本。
- API 文档。
- 架构、数据模型和任务状态图。
- 测试报告、手工验收记录和已知限制。
- 部署与备份说明。
- 阶段复盘、408 笔记索引和面试问题集。
