# 原型设计

## 信息架构

```text
登录
└── 工作台
    ├── 集合列表（默认 Inbox）
    ├── 链接列表
    │   ├── 保存链接
    │   ├── 任务状态
    │   └── 链接详情
    │       ├── 网页快照
    │       ├── 正文阅读
    │       ├── PDF
    │       └── 截图
    ├── 标签
    └── 搜索
```

## 页面线框

### 工作台

```text
+----------------+----------------------------------------------+
| 集合           |  [搜索]                 [+ 保存链接]         |
| Inbox          |----------------------------------------------|
| 技术           |  标题          状态      标签      保存时间    |
| 课程           |  文章 A        已完成     Java      09-12      |
| 论文           |  文章 B        抓取中     -         09-12      |
|                |  文章 C        失败       网络      09-12      |
| 标签           |----------------------------------------------|
| Java / 网络    |  分页                                        |
+----------------+----------------------------------------------+
```

### 链接详情

```text
+--------------------------------------------------------------+
| 返回 | 标题 | 原链接 | 重新采集 | 编辑 | 删除                  |
|--------------------------------------------------------------|
| [正文] [截图] [PDF] [HTML]                                   |
|                                                              |
| 阅读区域 / 图片预览 / PDF 预览 / 下载入口                     |
+--------------------------------------------------------------+
```

### 保存链接

```text
+--------------------------------------+
| URL *                                |
| 集合 [Inbox v]                       |
| 标签 [Java] [Spring] [添加]          |
| 标题（可留空自动提取）               |
| 描述                                 |
| [取消]                       [保存]   |
+--------------------------------------+
```

## 状态反馈

- 创建成功后立即跳转到详情页，状态为“等待抓取”。
- 页面每 3 秒轮询任务状态，完成后停止。
- 失败时显示错误类别、重试次数和“重新采集”按钮。
- 部分资产缺失时按类型显示“不可用”，不隐藏整个详情页。

## 前端范围

- Vue 3 + Vite + Pinia + Vue Router + Element Plus。
- 第一版不引入复杂状态缓存库；以页面数据和轮询为主。
- 路由：`/login`、`/collections`、`/links`、`/links/:id`、`/tags`、`/search`。
