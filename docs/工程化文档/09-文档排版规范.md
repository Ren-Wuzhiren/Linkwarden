# 文档排版规范

> **一句话速览**：本规范定义 `docs/` 下所有 Markdown 的块型、留白、关键词与 emoji 纪律，目标是把笔记从“解决方案”变成可扫读、可呼吸的知识产品。🐋

## 📌 适用范围

本规范约束 `docs/` 下所有 Markdown 文档的排版与信息承载方式。

它不约束事实本身。

测试数字、阶段编号、接口契约和结论仍然只来自代码、验收记录和真实运行结果。

## 🧩 术语速查

- **块型**：信息的呈现单位，例如表格、代码块、引用块、列表和散文。
- **速览**：H1 之后的一句话引用块，说明本篇解决什么问题。
- **术语速查**：术语搭配一句话定义的清单。
- **事实锁定**：排版改造不得改动事实的硬约束。
- **闭嘴条件**：某些上下文明确禁止使用 emoji 的规则。

## 🧩 块型优先序

能扫读的块型优先于需要逐字阅读的块型。

同一份信息，如果左边的块型可以表达，就不要用右边的块型。

```text
表格    → 状态、字段、编号映射、对比选型
代码块  → 关键词、标识符、路径、命令、结构图
引用块  → 一句话定位、速览、需要单独强调的判断
短列表  → 7 条以内的并列项
散文    → 因果解释、取舍说明
```

块型选择的判断依据是读者的动作。🧐

如果读者的动作是“扫一眼确认状态”，就用表格。

如果读者的动作是“复制一个标识符或命令”，就用代码块。

如果读者的动作是“理解为什么这样取舍”，才用散文。

---

## 🧩 散文逐句分段

解释性文字一个句子一段，句与句之间空一行。

判定散文的方法是排除法。

不是列表、不是表格、不是代码块、不是引用块的连续叙述文字，就是散文。

```text
空行本身就是呼吸手段。

一句一段在 Markdown 与 Notion 中都会真实生效。

所以呼吸感不必依赖额外装饰。
```

**清单不拆句。**

并列枚举、字段和状态仍然使用列表、表格或代码块。

列表超过 7 条时必须分组，或者改写成表格。

## 🧩 关键词与定义

关键词、标识符、路径和命令的枚举一律放进代码块。

代码块的语言标注只用下面这几种。

| 标注 | 用途 |
| --- | --- |
| `text` | 关键词、标识符、路径、结构图 |
| `powershell` | Windows 命令 |
| `bash` | Linux 命令 |
| `sql` | 数据库语句 |
| `yaml`、`json` | 配置与报文 |

术语密度高的正文型文档应当提供术语速查。

格式固定为一行一条，定义不超过 40 字。

```text
- **术语**：一句话定义
```

术语必须出自原文，禁止新造。

## 🧩 emoji 纪律

emoji 是标点和语义锚点，不是装饰。

删掉全部 emoji 之后，文档仍然必须完整、准确、可读。

职能型 H2 最多带一个前缀锚点。

信息与结构类：

- 📌 — 元信息、文档目的、背景
- 🧩 — 结构、规则、内容、组成
- 🕘 — 沿革、历史
- 🚩 — 阶段、里程碑

状态与动作类：

- ✅ — 状态、验收、结论
- 🧪 — 测试、验证
- ⚠️ — 边界、风险、不做什么
- 📝 — 下一步、待办

正文标点不承担结构职责，只在真的增加语义时使用。

- 🐋 — 主标识、章节收束
- 🧐 — 关键判断、需要校准的认知点
- 🧠 — 核心结论、记忆口诀
- 🔧 — 工程动作、修复手段
- 🌈 — 正常路径、成功链路
- ❄️、🏔️ — 失败路径、连锁失效
- 🔥 — 正在升温的问题

预算与闭嘴条件：

- 正文 emoji 全文不超过 12 个。
- 连续 emoji 不超过 2 个。
- 代码块、命令、报错、日志、路径和表格单元格内一律不用 emoji。
- 上面的词表属于定义性列举，不占用正文预算。

---

## 🧩 留白与分隔

所有非空块之间保留 1 个空行。

表格与代码块的前后各保留 1 个空行。

正文超过 120 行的文档，在大节之间插入 `---`。

## ⚠️ 事实锁定

排版改造只允许改变块的类型、位置和呈现方式。

以下内容禁止改动。

```text
测试数字与验收数字
阶段编号与旧编号映射
类名、表名、接口路径、命令行
Markdown 链接目标
结论性表述
```

派生视图只允许由原文直接推导。

禁止为了满足“每个概念配一个例子”而新造例子。

## ✅ 自检清单

| 检查项 | 通过标准 |
| --- | --- |
| 速览 | H1 后第一个块是引用块 |
| 表格 | 全文至少 1 个 |
| 代码块 | 全文至少 1 个，且关键词枚举没有散落在散文里 |
| 分段 | 散文段落内部不含第二个句末标点 |
| 列表 | 最长连续列表不超过 7 条 |
| emoji | 正文不超过 12 个，代码块与表格单元格内为 0 |
| 事实 | 数字、编号、标识符、链接目标与改造前一致 |
