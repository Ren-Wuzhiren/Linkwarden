## 阶段 1.2：标识与关联

已观察到的真实实现：

- `requestId` 用 UUID 作为缺失或非法请求头时的替代标识。
- UUID 的设计目标是实际使用中极低碰撞概率，不等于数学意义上的绝对唯一，也不能作为安全凭证。
- `ThreadLocal` 把同一个请求 ID 与当前处理线程关联起来，但本阶段没有研究 `ThreadLocalMap` 的底层结构。
