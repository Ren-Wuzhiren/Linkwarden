## 阶段 1.2：HTTP 请求头、端口与健康检查

已通过真实服务验证：

- 浏览器或客户端通过 HTTP 访问 Tomcat 的 `8080` 端口。
- `X-Request-Id` 是应用层请求/响应头，用于关联同一次请求，不负责 TCP 可靠性，也不是认证凭证。
- MySQL 宿主端口是 `3307`，Redis 宿主端口是 `6380`；端口映射属于应用与外部服务之间的连接约定。
- `/actuator/health` 会检查应用、MySQL 和 Redis 状态；Redis 密码错误时整体状态为 `DOWN`，修正连接配置后返回 `UP`。
- `SPRING_DATA_REDIS_PASSWORD` 覆盖本地 YAML，说明环境变量是部署环境和应用配置之间的高优先级输入。

当前边界：

- DNS、TLS、HTTP 重定向和 SSRF 防护尚未真实实现，保留在后续阶段。
- Filter 运行在 Tomcat 接收请求之后、Controller 之前，它处理的是应用层请求生命周期，不替代网络层可靠性机制。
