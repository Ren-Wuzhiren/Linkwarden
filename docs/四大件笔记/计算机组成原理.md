## 待项目验证

- 浏览器渲染、PDF/图像生成的资源消耗。
- 文件 I/O、缓存与内存缓冲。

## 阶段 1.2：从源码到 JVM

已观察到的真实过程：

- Maven 把 Java 17 主代码编译到 `target/classes`，把测试代码编译到 `target/test-classes`。
- Spring Boot 启动后由 JVM 加载应用类和依赖，随后启动内嵌 Tomcat 并监听 8080 端口。
- `mvn -pl backend test` 报告 6 个测试通过，说明编译产物和测试运行环境已经能够协同工作。

当前边界：

- 还没有直接观察 CPU、缓存、指令流水或内存带宽层面的现象。
- 后续 Playwright 截图、PDF 和图像处理阶段再记录资源消耗与文件 I/O。
