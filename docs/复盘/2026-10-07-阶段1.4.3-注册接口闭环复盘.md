# 2026-10-07 阶段 1.3（旧 1.4.3）注册接口闭环复盘

## 本阶段目标

完成注册接口从 HTTP Controller 到真实 MySQL 落库的完整闭环：

- `AuthService` 负责注册业务规则。
- `AuthController` 负责 HTTP 协议转换。
- BCrypt 负责密码哈希。
- `AppUserMapper` 负责用户持久化。
- Testcontainers 使用真实 MySQL 和 Redis 验证链路。

## 已完成内容

- `AuthService`：注册开关、用户名/邮箱重复检查、BCrypt 哈希、固定时间和唯一键冲突翻译。
- `AuthController`：`POST /api/v1/auth/register`，成功返回 `201 Created`。
- `UserSummary`：只暴露安全字段，`createdAt` 使用 ISO 8601 字符串输出。
- `AuthControllerTest`：6 个 MockMvc 测试覆盖成功和错误契约。
- `AuthRegistrationIntegrationTest`：3 个真实数据库集成测试覆盖注册落库、重复用户名和重复邮箱。
- `AuthServiceTest`：6 个服务层测试覆盖注册业务分支。

## 关键问题与结论

- `AuthController.java` 最初被放入 `src/test/java`，已移动到 `src/main/java`；生产代码和测试代码必须保持源码目录边界。
- Controller 成功消息从“创建成功”修正为“注册成功”，与注册用例语义一致。
- standalone MockMvc 不会自动使用 Spring Boot 的 Jackson 配置，导致 `Instant` 输出数字时间戳；在 `UserSummary.createdAt` 上明确使用 `@JsonFormat(shape = JsonFormat.Shape.STRING)` 后，输出稳定为 ISO 8601。
- 测试方法统一使用 `// [测试意图] ...` 单行注释，说明测试验证的行为和边界。
