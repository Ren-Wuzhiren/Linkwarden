# 学习笔记索引

> **一句话速览**：本目录一条概念一个文件，每条讲透"是什么、怎么做的、会踩什么坑"，上限 40 条。🐋

## 🧩 这里放什么

只有同时满足三条的概念才进来。

| 条件 | 说明 |
| --- | --- |
| 我真的被它卡过 | 在实现时确实因此停顿或提问过 |
| 它有复用价值 | 以后还会遇到，不是一次性配置 |
| 一个最小例子能说清 | 说不清说明还没到能记的粒度 |

## 🧩 每条长什么样

```text
# <概念名>

> 触发它的契机：<一句话，当时在做什么、被什么卡住>

## 它是什么、解决什么问题
## 怎么做的（含一个最小例子）
## 会踩的坑
## 我当时的理解
```

最后一段是我自己的原话，由 Codex 一字不改地记下来。

讲解层由 Codex 写。
